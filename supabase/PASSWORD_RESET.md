# Password reset deployment

Passwords containing `T2T@` are ordinary passwords. Login reset requirements
come from `public.users.must_reset_password`, never from the password prefix.

Deploy `functions/admin-reset-password/index.ts` as an Edge Function named
`admin-reset-password` in project `lqydkbfxbaxrgbvdznxn`. Use the Supabase
dashboard Edge Function editor or the Supabase CLI:

```
supabase functions deploy admin-reset-password --project-ref lqydkbfxbaxrgbvdznxn
```

The function checks the caller's actual Auth token and approved active admin
profile before using the server-only service-role key to update a password.
Supabase supplies its URL and service-role environment variables to hosted
Edge Functions. Never put a service-role key in a VITE_ variable or browser.
The frontend reports failure if the function is missing or the reset is rejected.

Existing passwords generated by the old CRM were only stored in localStorage.
They are not Auth passwords. An account that cannot sign in first needs a
one-time password update through the Supabase Auth Admin API or dashboard.
Do not delete or recreate users: their Auth IDs link their sales and profiles.
Email recovery cannot deliver to dummy mailboxes.

For the project owner's locked-out Pavan account, the optional one-time
`recover_pavan_password.sql.example` template targets only the existing
`pavan@time2trade.com` Auth account. Replace its password placeholder privately
in the Supabase SQL Editor and run it as the project owner. It preserves the
account ID and does not change profile roles or approval. Do not commit or share
the completed query. Use the Auth API for ongoing application password resets.

Verify a rejected password update leaves reset flags intact, and a successful
one persists after logout and login from another browser. Test admin reset with
an approved admin token and verify employee, manager, expired and missing tokens
are rejected. These live checks require deploying the function first.

Local regression checks: `node scripts/check-password-service.mjs`,
`node scripts/check-access-control.mjs`, and `npm run build`.
